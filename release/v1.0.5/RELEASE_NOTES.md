# ObsidianToMP v1.0.5

## Highlights
- Added queued draft publishing for Codex / Claude Code handoff.
- Added command `obsidian-to-mp-publish-queued-draft`.
- Added command `obsidian-to-mp-publish-active-draft`.
- Added settings UI for generating a current-note publish request and executing the queue.
- Added `content/.obsidiantomp/publish-request.json` -> `publish-result.json` workflow.

## Manual Install
Unzip `obsidian-to-mp-v1.0.5.zip` into:

```text
<Vault>/.obsidian/plugins/obsidian-to-mp
```

Then restart Obsidian and enable `ObsidianToMP`.
